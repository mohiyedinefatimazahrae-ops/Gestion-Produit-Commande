# Gestion de Produits et Commandes

Système de gestion en PHP natif avec Bootstrap.

## Fonctionnalités
- Authentification
- Gestion clients, produits, commandes

## Installation
1. Cloner le repo
2. Copier connexion.example.php vers connexion.php
3. Configurer la base de données
4. Importer database.sql

## Technologies
- PHP natif (PDO)
- MySQL
- Bootstrap
